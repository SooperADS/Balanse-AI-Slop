# Баланс

Домашняя бухгалтерия в браузере: профили, доходы, расходы, конвертация RUB/USD/EUR, категории, теги и плановые записи. Сервер — Python, Flask и Waitress; данные — SQLite. Интерфейс адаптирован для ПК и телефона, сборка JavaScript не нужна.

## Запуск

Python 3.11+; проект проверен на Python 3.14.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

При первом запуске создаётся `config.toml` и выводится подсказка. Отредактируйте настройки и повторите `python main.py`. Пустой пароль разрешён. Далее запуск возможен одной командой `.venv/bin/python main.py`; остановка — Ctrl+C.

На сервере откройте **http://127.0.0.1:8080**, на другом домашнем устройстве — `http://локальный-IP-сервера:8080`. Адрес интерфейса можно узнать через `ip -brief address`. При необходимости разрешите порт в брандмауэре домашней сети.

## Настройки

Пример — [config.example.toml](config.example.toml). Изменения применяются после перезапуска.

| Ключ TOML | По умолчанию | Назначение |
| --- | --- | --- |
| `auth.password` | `""` | Общий пароль, хранится в конфигурации открытым текстом |
| `auth.max_attempts` | `5` | Попытки входа с одного IP за 15 минут |
| `server.host` | `"0.0.0.0"` | Доступ по домашней сети; `"127.0.0.1"` — только с сервера |
| `server.port` | `8080` | Порт HTTP-сервера |
| `storage.database` | `"data/budget.sqlite3"` | Путь базы относительно папки `main.py` либо абсолютный путь |

Профили свободно переключаются после общего входа. Сессия сохраняется в БД без срока истечения на сервере; браузер может удалить или ограничить хранение cookie. Выход отзывает текущую сессию, смена пароля и перезапуск — все старые. Формы защищены от CSRF. Соединение работает по HTTP без шифрования и предназначено для домашней сети.

## Правила учёта

- Валюты учитываются отдельно. Текущий баланс — начальный капитал плюс наступившие по времени движения денег. Капитал можно изменить без записи в журнале; отрицательные суммы капитала и баланса разрешены.
- В форме суммы положительные; в БД доход положителен, расход и списание трансфера отрицательны. Хранятся целые копейки/центы. Комментарий обязателен.
- Трансфер меняет две валюты одной записью. Поля курса и получения связаны; изменение суммы списания сохраняет курс. Результат округляется до копейки/цента, половины — вверх. На сервер передаются суммы и валюты, курс не хранится.
- Время операций — локальное время сервера. Будущие записи выделены голубым, исключены из текущего баланса и автоматически становятся текущими при наступлении их времени. Страница пересчитывается при запросе.
- «Без категории» означает `category_id = NULL`. При удалении категории её записи сохраняются без категории; удаление тега убирает только связи. Выбор нескольких тегов в фильтре требует наличия **всех** выбранных тегов.
- Статистика разделена на текущую и плановую. Доступны день, последние 7 дней по выбранную дату включительно, месяц, год и произвольный диапазон с обеими включёнными датами. Трансферы учитываются отдельно от доходов и расходов. Суммы по нескольким тегам могут пересекаться.
- Формы проверяются в браузере и на сервере. Удаление записей и профилей необратимо.

## Данные и проверки

`config.toml` и `data/` исключены из Git. Для резервной копии остановите сервер и скопируйте файл SQLite; восстанавливайте его также при остановленном сервере. Копия включает сессии. Автоматических миграций схемы нет.

```bash
.venv/bin/python -m unittest discover -s tests -v
tsc --project jsconfig.json
```

Тесты используют временные базы; HTTP-тест открывает временный порт на `127.0.0.1`. Команда `tsc` требует установленного TypeScript и проверяет JSDoc без генерации файлов. Pyright/BasedPyright использует [pyrightconfig.json](pyrightconfig.json) и окружение `.venv`.

Структура, модель данных и связи HTML/JS/CSS описаны в [памятке разработчика](docs/development.md). Назначение функций и типов приведено в docstring и JSDoc исходников.
